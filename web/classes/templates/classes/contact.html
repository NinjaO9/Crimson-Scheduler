Bug Reports

If you find an issue with the site, the best place to report it is the project's public repository. Please label the issue as bug if possible.

You may also email suggestions to the address above. For suggestion emails, please begin the subject with [Suggestion]. Before suggesting a feature, please check the active GitHub issues to see whether it has already been suggested or is already in development.
