Using Crimson Scheduler

Desktop quick guide

Desktop search screenshot

Find a class

Pick a campus and term, then search by subject + number or by course title.

Desktop add screenshot

Add your section

Select the section you want. If a lab is required, choose both the lecture and lab before adding.

Desktop remove screenshot

Remove a class

Click a class on the calendar to remove it. Use Remove in the misc list for arranged, online, or TBA classes.

Desktop-only tips

  • Hover over a section in search results to preview where it lands on your calendar.
  • Hover over a class on your schedule to see details like instructor, location, and meeting time.
  • Use Options to hide weekends when you want a cleaner Monday-Friday view.

Mobile guide

Mobile search screenshot

Start in Search

Use the Search tab to choose a campus and term, then search by course number or title.

Mobile add screenshot

Tap Add

Select a section, add it, and the app will jump to your Schedule tab.

Mobile remove screenshot

Tap to remove

Tap a calendar block to remove it, or use Remove for classes in the misc list.

Tip: use Actions to share a code, import a code, or export your schedule image.
